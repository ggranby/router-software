## Messages

| Name | Type | Direction | Payload | Meaning |
|---|---|---|---|---|
| `HELLO_REQUEST` | `0x01` | bridge/master -> node | `empty` | Ask a node to identify itself. The node answers with HELLO. |
| `HELLO` | `0x02` | node -> bridge/master | `[proto_version:u8][role:u8][fw_major:u8][fw_minor:u8][catalog_hash:u32][board_id:8][name_len:u8][name:name_len]` | Identity and capabilities. role is a bit set of ROLE_*. |
| `DESCRIBE_REQUEST` | `0x03` | bridge/master -> node | `[page:u8]` | Ask for one page of the node's control list. |
| `DESCRIBE` | `0x04` | node -> bridge/master | `[page:u8][page_count:u8]([control_id:u16][role:u8])*` | Controls the node owns. role 0 = input (node -> sim), 1 = output (sim -> node). |
| `SUBSCRIBE` | `0x05` | node -> bridge | `[scope:u8]([id:u16])*` | Replace the node's output subscription. scope is one of SUBSCRIBE_*. |
| `STATE` | `0x10` | bridge -> nodes (broadcast) | `([control_id:u16][kind:u8][value])*` | Sim state keyed by catalogue id. kind is one of VALUE_*: BOOL/POSITION value is u8, ANALOG is u16, TEXT is [len:u8][bytes]. |
| `INPUT` | `0x11` | node -> bridge | `([control_id:u16][action:u8][arg:u16])*` | Cockpit input events. action is one of ACTION_*. The frame sequence number is used for duplicate detection and ACK. |
| `SYNC_REQUEST` | `0x12` | bridge/master -> node | `empty` | Ask the node to report the physical position of every input it owns. |
| `SYNC_REPORT` | `0x13` | node -> bridge | `[flags:u8]([control_id:u16][value:u16])*` | Physical positions (position index, or 0-65535 for axes). flags bit 0 = last page of the report. |
| `MODE` | `0x20` | bridge -> nodes | `[mode:u8]` | Change operating mode. mode is one of MODE_*. |
| `MODE_ACK` | `0x21` | node -> bridge | `[mode:u8]` | The mode the node applied. |
| `ACK` | `0x30` | any | `[acked_seq:u8]` | The frame with sequence acked_seq was accepted. |
| `NACK` | `0x31` | any | `[acked_seq:u8][reason:u8][control_id:u16]` | The frame was rejected. reason is one of NACK_*. |
| `DIAG_REQUEST` | `0x40` | bridge/master -> node | `empty` | Ask for diagnostic counters. |
| `DIAG` | `0x41` | node -> bridge | `[crc_errors:u16][framing_errors:u16][overflows:u16][dropped_inputs:u16][last_error:u8][free_ram:u16][text_len:u8][text]` | Counters since boot plus an optional short text message. |
| `CONFIG` | `0x50` | bridge/master -> node | `[key:u8][value...]` | Change a setting. key is one of CFG_*. The node answers ACK or NACK. |
| `HEARTBEAT` | `0x60` | any | `empty` | Keeps an idle USB link alive. |
| `POLL` | `0x70` | master -> slave | `empty` | The addressed slave may transmit exactly one frame now. |
| `POLL_EMPTY` | `0x71` | slave -> master | `empty` | Reply to POLL when the slave has nothing to send. |
| `DISCOVER` | `0x72` | master -> slaves (broadcast) | `[slot_count:u8][slot_ms:u8]` | All slaves answer HELLO in one random slot, including already-polled slaves, to reveal duplicate addresses. |
| `BUS_EVENT` | `0x73` | master -> bridge | `[event:u8][address:u8]` | A slave joined, dropped off or has an address conflict. event is one of BUS_*. |

## Addresses

| Name | Value | Meaning |
|---|---|---|
| `BROADCAST` | `0x00` | Every node processes the frame. Never used as a source. |
| `FIRST_SLAVE` | `0x01` | Lowest RS-485 slave address. |
| `LAST_SLAVE` | `0xEF` | Highest RS-485 slave address. |
| `BRIDGE` | `0xFD` | The PC bridge (hornet-link.exe). |
| `LINK_NODE` | `0xFE` | The board attached to the PC over USB: a bus master or a standalone panel. |
| `UNASSIGNED` | `0xFF` | A slave that has no bus address yet. Only used as a source in HELLO during discovery. |
